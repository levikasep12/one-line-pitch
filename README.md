A program that writes one pitch sentence to `/output/entry.txt`: tell an AI agent your app idea in plain words and it builds a working first version, no code, no setup, and you keep only what you love. One sentence, 181 characters, built for make.fun's "A Day of One-Line Pitches" bounty.

## Run it

```sh
node main.ts
```
